Fetch Stage: Ready to Begin

In a Von Neumann architecture, program instructions and data share Main Memory (RAM). Watch how the CPU registers and buses work together on every clock tick.

📝 OCR J277 Exam Mark-Scheme Tip State clearly that the PC holds the memory address of the next instruction, whereas the MDR holds the actual instruction or data fetched from RAM.

Program Counter (PC)

Holds the memory address of the next instruction to be fetched from Main Memory. Increments by 1 during Fetch.

Memory Address Register (MAR)

Holds the memory address of the current instruction or data being read from or written to RAM via the unidirectional Address Bus.

Memory Data Register (MDR)

Holds the actual instruction or data fetched from RAM (or waiting to be written to RAM) via the bidirectional Data Bus.

Accumulator (ACC)

Stores intermediate and final results of arithmetic and logic calculations performed by the ALU.

Control Unit (CU) & ALU

CU: Decodes instructions and sends Read/Write/Clock signals. ALU: Executes addition, subtraction, and logical comparisons.

Cache

Very fast, small memory inside the CPU storing frequently used instructions and data to speed up access compared to RAM.
