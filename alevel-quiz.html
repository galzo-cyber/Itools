H446 Spec

Processor Architecture & Pipelining

RISC vs CISC: CISC processors have complex, multi-clock instructions with hardware emphasis. RISC processors have simple, single-cycle instructions with compiler emphasis and pipelining.

Key Formula: Speedup = (Time without pipeline) / (Time with pipeline)

Big-O Complexity & Algorithms

Binary Search: O(log n), Merge Sort: O(n log n), Bubble Sort: O(n²), Dijkstra's Algorithm: O((V + E) log V) with priority queue.

Dijkstra finds shortest path in weighted graphs using greedy traversal.

Boolean Algebra & Karnaugh Maps

De Morgan's Laws: NOT (A AND B) = NOT A OR NOT B; NOT (A OR B) = NOT A AND NOT B. Distribution: A AND (B OR C) = (A AND B) OR (A AND C).

K-Maps group adjacent 1s in powers of 2 (1, 2, 4, 8, 16) with Gray code ordering.

Relational Databases & SQL (3NF)

1NF: Atomic data, no repeating groups. 2NF: 1NF + no partial key dependencies. 3NF: 2NF + no transitive non-key dependencies.

ACID properties: Atomicity, Consistency, Isolation, Durability.
